# 《魔力寶貝 Online》(Cross Gate) 100% 還原度 ARPG 豪華擴充版

## 遊戲簡介
本作使用 **Godot 4.7.2 引擎 (Forward+ / GL Compatibility)** 開發，在原汁原味 100% 還原經典《魔力寶貝》（Cross Gate）的核心世界觀、角色職業、寵物封印、元素相剋、地圖探索與經典技能的基礎上，全面加入了 **100+ 種魔力經典魔物**、**法蘭城中央愛謝拉女神防守戰**、**50 波怪潮進攻與各大領主 BOSS 戰**、以及 **每 5 級 / BOSS 通關 Roguelike 特殊天賦三選一（含全自動施法）** 系統！

---

## 🌟 豪華擴充核心系統

### 1. 100+ 種魔力經典魔物大圖鑑 (`MonsterDatabase.gd`)

- **特殊系**：史萊姆、果凍史萊姆、熔岩史萊姆、金屬史萊姆、炸彈、漂浮炸彈、寶箱怪、純白嚇人箱、純淨水晶怪、暗影史萊姆王等。
- **昆蟲系**：黃蜂、殺人蜂、異型蜂、綠螳螂、赤目螳螂、死灰螳螂、致命螳螂、土蜘蛛、死亡土蜘蛛、劇毒土蠍、巨角甲蟲、狂暴獨角仙王等。
- **人形系**：哥布林、紅帽哥布林、矮人戰士、狂暴矮人、盜賊、強盜頭目、死靈騎士、黑暗狂戰士、暗影刺客、魔導術士、法蘭叛軍勇士、異端審判官等。
- **野獸系**：穴熊、赤目黑熊、北極熊、地獄看門犬、狂暴犬、貓妖、貓妖狂戰士、狂暴野豬、雪狼、銀狼王、恐狼、遠古奇美拉等。
- **植物系**：樹精、死亡樹精、妖草、曼陀羅草、仙人掌、巨型食人花、劇毒藤蔓怪、遠古神木守衛、蘑菇精、毒蕈魔王等。
- **不死系**：喪屍、腐屍、骷髏戰士、骷髏斧手、骷髏法師、死神、幽靈、怨靈主教、暗黑僧侶、巫妖王、吸血鬼公爵、亡靈統領等。
- **飛行系**：小惡魔、使魔、小蝙蝠、掃把蝙蝠、大惡魔、石像鬼、墮落石像鬼、哈比鳥人、鷹身女妖塞壬、墮落天使等。
- **金屬系**：血腥之刃、烈風之刃、殺手雄、鐵剪蟹、純銀巨像、黃金傀儡王、鋼鐵魔像、發條機甲狂魔等。
- **龍系**：蜥蜴戰士、水龍蜥、火龍蜥、地龍巨蜥、雙翼翼龍、狂雷巨龍、黑龍幼獸、古龍守護者、滅世紅龍、幽冥骨龍等。
- **邪魔 / 領主 BOSS 系**：熱砂之歐茲那克、露比 (Ruby)、改造殭屍統領、猶大 (Judas)、阿卡斯、佛利波羅、巴洛斯、逆牛米諾陶洛斯、暗黑巫王、軍神李貝留斯！

### 2. 中央愛謝拉女神防守戰 (`GoddessStatue.gd`)
- 位於法蘭城中央的愛謝拉女神像擁有 8000 點生命值。
- **神聖光環**：玩家與寵物進入光環範圍，每秒自動恢復 +5% HP 與 +5% MP！
- 防守 50 波入侵魔物，避免女神之像遭到摧毀！

### 3. 50 波持續怪潮入侵與領主 BOSS (`WaveManager.gd`)
- 難度階梯式上升，每 5 波迎戰一隻史詩 BOSS：
  - Wave 5: **熱砂之歐茲那克**
  - Wave 10: **露比 & 炸彈小隊**
  - Wave 15: **改造殭屍統領**
  - Wave 20: **猶大 (Judas)**
  - Wave 25: **阿卡斯 (Akers)**
  - Wave 30: **佛利波羅 (Foribolo)**
  - Wave 35: **巴洛斯 (Baros)**
  - Wave 40: **逆牛 米諾陶洛斯**
  - Wave 45: **暗黑巫王**
  - Wave 50: **最終決戰 — 軍神 李貝留斯**

### 4. 每 5 級 / BOSS 通關 Roguelike 特殊天賦三選一 (`BuffManager.gd`)
- **自動施法系列**：
  - `天賦【四方氣功彈】`：每 2.5 秒自動向東南西北四方轟出 4 枚貫穿氣功彈！
  - `天賦【真·乾坤破空】`：每 3.5 秒自動鎖定最近敵人發動 320% 霸體乾坤一擲！
  - `天賦【天降神罰隕石】`：每 5 秒自動在敵人密集處召喚巨型地屬性隕石轟炸！
  - `天賦【極凍冰霜之環】`：每 4 秒在自身周圍引爆大範圍冰環，造成水屬性傷害並擊退！
- **戰鬥與強化系列**：
  - `天賦【連擊·無盡狂暴】`：手動連擊斬擊次數提升至 6 段！
  - `天賦【四系全元素掌控】`：地水火風元素剋制增傷由 30% 暴增至 75%！
  - `天賦【嗜血暴擊汲取】`：暴擊時將 25% 傷害轉化為生命恢復！
  - `天賦【神行幻影步】`：翻滾無敵時間延長 100%，並在原地留下自爆殘影！
  - `天賦【寵物狂化共鳴】`：寵物攻擊力與攻速 +80%，與玩家合擊機率 100%！
  - `天賦【神之封印財富】`：封印成功率 +30%，怪物掉落魔石與金幣數量 +100%！

## 🚀 啟動遊戲方法
1. 在資料夾直接雙擊執行 `run_game.bat` 即可立刻開啟遊戲！
2. 或在 PowerShell 命令列輸入：
   ```powershell
   & ".\tools\godot\Godot_v4.7.2-stable_win64.exe" --path .
   ```
