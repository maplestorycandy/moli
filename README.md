# 《魔力寶貝 Online》(Cross Gate) 100% 還原度 ARPG 豪華正式版

## 遊戲簡介
本作使用 **Godot 4.7.2 引擎 (Forward+ / Web / Compatibility)** 開發，100% 原汁原味還原經典《魔力寶貝》（Cross Gate）的核心世界觀、角色職業、寵物封印、元素相剋、地圖探索與經典技能。

- 🌐 **線上網頁遊玩版 (GitHub Pages)**: [https://maplestorycandy.github.io/moli/](https://maplestorycandy.github.io/moli/)
- 💻 **GitHub 倉庫**: [https://github.com/maplestorycandy/moli](https://github.com/maplestorycandy/moli)

## 🎮 鍵盤與滑鼠操作指南

| 按鍵 | 功能說明 |
| :--- | :--- |
| **W, A, S, D** / 方向鍵 | 八方向角色流暢移動 |
| **滑鼠左鍵** / **J** | 普通攻擊（三段連斬與劍氣刀光） |
| **Space 空格** / **K** | 翻滾閃避（享有短暫無敵幀與殘影） |
| **數字鍵 1** / **Q** | 技能【連擊】：快速向前衝刺發動 3~6 段高速連環斬擊 |
| **數字鍵 2** / **E** | 技能【乾坤一擲】：金光霸體蓄力，造成 320% 巨額爆發傷害與劇烈震屏 |
| **數字鍵 3** / **R** | 技能【氣功彈】：向滑鼠指向凝聚並射出貫穿多名敵人的念彈 |
| **數字鍵 4** | 技能【超強隕石魔法】：召喚魔法陣並引導巨型隕石轟炸目標地面 |
| **G 鍵** | 投擲【封印卡】：瞄準 680+ 種野怪殘血封印捕捉，收服為新寵物！ |
| **T 鍵** | 切換寵物戰術：【進攻模式】/【護衛模式】/【待命模式】 |
| **F 鍵** / **Enter** | 與 NPC 互動（全域傳送石、醫院護士治療、魔石商人、東門守衛） |
| **C 鍵** | 開啟/關閉【冒險者狀態與配點面板】（體力/力量/強度/速度/魔法） |
| **I 鍵** | 開啟/關閉【冒險者背包】（道具、魔石、封印卡、藥水使用） |
| **P 鍵** | 開啟/關閉【魔力寵物隊伍與資質面板】（滿檔/掉檔資質、寵物出戰） |

## 🌟 核心特色系統

### 1. 全 12 大系、680+ 隻寵物原版高畫質圖鑑 (`MonsterDatabase.gd`)
依據官方與蔚藍幻境圖鑑資料庫，收錄魔力寶貝全 12 大系共 680+ 種經典魔物，並已下載 1000+ 張原版 GIF/PNG 精靈圖直接渲染：
- **野獸系** (111 隻)：虎人、貓妖、羅剎、穴熊、赤目黑熊、北極熊、貓熊、大地翼龍、狂暴野豬、雪狼、銀狼、恐狼等。
- **不死系** (57 隻)：殭屍、腐屍、骷髏戰士、骷髏斧手、骷髏法師、死神、幽靈、怨靈、巫妖、吸血鬼等。
- **飛行系** (68 隻)：小惡魔、使魔、小蝙蝠、掃把蝙蝠、大惡魔、石像鬼、哈比、鷹身女妖塞壬、墮落天使等。
- **昆蟲系** (56 隻)：黃蜂、殺人蜂、異型蜂、綠螳螂、赤目螳螂、死灰螳螂、致命螳螂、土蜘蛛、劇毒土蠍、獨角仙王等。
- **植物系** (61 隻)：樹精、死亡樹精、妖草、曼陀羅草、仙人掌、巨型食人花、劇毒藤蔓、蘑菇精、毒蕈等。
- **特殊系** (54 隻)：史萊姆、果凍史萊姆、熔岩史萊姆、金屬史萊姆、炸彈、漂浮炸彈、寶箱怪、純白嚇人箱、純淨水晶怪等。
- **金屬系** (67 隻)：血腥之刃、烈風之刃、殺手雄、鐵剪蟹、純銀巨像、黃金傀儡、鋼鐵魔像、發條機甲等。
- **龍系** (53 隻)：蜥蜴戰士、水龍蜥、火龍蜥、地龍巨蜥、雙翼翼龍、黑龍幼獸、古龍守護者、滅世紅龍、幽冥骨龍等。
- **人形系** (69 隻)：哥布林、紅帽哥布林、矮人戰士、盜賊、強盜頭目、死靈騎士、暗影刺客、魔導術士等。
- **邪魔系** (51 隻)：熱砂之歐茲那克、露比 (Ruby)、猶大 (Judas)、阿卡斯、佛利波羅、巴洛斯、逆牛、軍神李貝留斯等。
- **改造寵** (58 隻)：改造殭屍、改造蜥蜴戰士、改造陰影、改造旋律影子、改造烈風之刃等。
- **家族獸** (104 隻)：法蘭家族守護神獸、神聖麒麟、遠古巨獸等。

### 2. 10 大世界地圖與全域傳送石 (`WorldMap.gd`)
法蘭城中央配備傳送石，一秒瞬移至 10 大地圖探險：
1. **法蘭城 王都** (中央女神像、醫院、商店、傳送石中樞)
2. **芙蕾雅島·東門原野** (昆蟲系 & 特殊系生態)
3. **哈巴魯東邊洞穴** (野獸系 & 昆蟲系生態)
4. **靈堂·地下迷宮** (不死系生態)
5. **國營第24號坑道** (金屬系 & 人形系生態)
6. **維諾亞村與水之洞穴** (植物系 & 龍系生態)
7. **烏克蘭村·忍者之里** (人形系 & 改造寵生態)
8. **索奇亞荒漠·奇利村** (野獸系、昆蟲系 & 植物系生態)
9. **莎蓮娜島·雪山之巔** (野獸系、飛行系 & 金屬系生態)
10. **阿卡斯祭壇·神域深淵** (邪魔系、龍系 & 家族獸生態)

### 3. 法蘭城愛謝拉女神守護防守戰與 50 波急速怪潮
- 女神像擁有 8000 HP，神聖光環每秒恢復玩家/寵物 +5% HP & MP。
- 怪物自城外 **【暗黑魔界裂隙傳送門】** 以 0.15s 高頻率急速湧出，渡過東門大橋衝擊法蘭城。
- 支援「⚡ 立即出怪」隨時開啟下一波！
